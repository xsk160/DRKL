# DRKL
This is the code for the paper "Decoupled Reverse Kullback-Leibler: Rethinking Knowledge Distillation Loss for Bridging GNNs and MLPs."

DRKL.py is the core loss function in this paper, which is a plug-and-play encapsulated module. You can use it in any graph knowledge distillation framework to further improve the prediction performance of student MLP.
